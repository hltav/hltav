## About me

Backend-focused software engineer working with **Node.js, TypeScript, Go and PHP**.

I currently contribute as **Technical Lead and Backend Maintainer at [Candidate](https://github.com/Cla-Code-Community/candidate)** and develop **[RT Sports Manager](https://rtsportsmanager.com)**, a sports bankroll management product.

My main interests are backend architecture, service communication, performance, testing, Docker infrastructure and production reliability.

## Featured work

### [Candidate](https://github.com/Cla-Code-Community/candidate)

Open-source job aggregation platform composed of a Node.js API, Go scraper, React applications, PostgreSQL and Valkey.

As Technical Lead and Backend Maintainer, I work with architecture, code reviews, releases, production support, security, testing and performance.

A recent Go-based scraper evolution reduced the execution time of 5–6 keyword batches from approximately **5–9 minutes to 15–20 seconds**.

`Node.js` `TypeScript` `Go` `PostgreSQL` `Valkey` `Docker` `CI/CD` `Observability`

### RT Sports Manager

Sports bankroll management product currently under active development.

The platform includes authentication, bankroll and betting management, transactional emails and sports statistics. Its architecture is evolving to use **Go and gRPC for intensive processing**, while Node.js remains responsible for the main application and business workflows.

[Backend](https://github.com/hltav/pgbsports_project) • [Frontend](https://github.com/hltav/rtsm_dashboard) • [Application](https://rtsportsmanager.vercel.app)

`NestJS` `Fastify` `Next.js` `PostgreSQL` `Prisma` `Go` `gRPC`
