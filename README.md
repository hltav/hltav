## About me

I'm a backend-focused software engineer experienced in building APIs, distributed services and production infrastructure with **Node.js, TypeScript, Go and PHP**.

I currently work as a **Technical Lead and Backend Maintainer at [Candidate](https://github.com/Cla-Code-Community/candidate)**, an open-source job aggregation platform composed of a Node.js API, Go scraper, React applications, PostgreSQL, Valkey and a complete observability stack.

Some of my recent work includes:

- Leading backend architecture, code reviews, releases and production operations.
- Reworking scraping workloads from Node.js/TypeScript to Go.
- Reducing the execution time of 5–6 keyword batches from approximately **5–9 minutes to 15–20 seconds**.
- Building authentication, RBAC, PII protection, caching and asynchronous processing.
- Designing REST and gRPC communication between services.
- Working with automated tests, CI/CD, Docker and production observability.

I'm currently focused on backend and full-stack opportunities where I can contribute to architecture, performance, reliability and product evolution.
